Crypthon

An open-source encryption + backup tool that just works. No questions.

RoleDeveloper

Year2025
LinksSource ↗

Overview

Crypthon is a small bare-bones GUI tool: point it at a folder of any kind, and it encrypts all of them - using hybrid encryption - and then upload them all to any cloud service you like, with no server and no database to maintain.

The problem

I wanted an easier way to backup my data safely then to encrypt every file one by one and anually uploading them that wasn't a subscription based or server-side application. But instead works on the directives of the user and is entirely customizable.

The approach

The GUI interface is intentionally boring: create a key pair, select a folder or a file, generate the encrypted versions of each file and choose what cloud solution you wanted them to be uploaded. Ordering and instructions come from the settings user selects before runnning the program. The user is the source of truth and is in full control of what happens to the files.

The result

You don't need upload your files one by one or wonder if the clooud platform really is end to end encrypted. You can just point Crypthon at a folder and let it do the rest. No need to worry about your backups and their safety anymore. It's fast, efficient and easy to use.
