Project

Routewise

A trip-planning tool that turns a rough list of places into an optimized day-by-day route, built to replace my own spreadsheet habit.

RoleDesigner & Developer
StackReact, Node, Maps API
Year2026
Links

Overview

Every trip I planned started the same way: a spreadsheet with a list of places, a lot of tab-switching to a map to guess at distances, and a lot of manual reshuffling when I realized two "nearby" places were actually forty minutes apart. Routewise exists to skip that part.

You paste in a list of places you want to visit, and it lays them out across however many days you're there, grouping by proximity and respecting rough opening hours, so the plan you end up with is one you could actually walk without doubling back across town.

The problem

Trip-planning tools I tried either wanted a lot of manual setup before they were useful, or optimized for "prettiest itinerary" over "itinerary you'd actually follow." I wanted something closer to a scheduling algorithm than a scrapbook — optimize the boring part, leave the interesting decisions to me.

The approach

The core of it is a routing pass that clusters places by geographic proximity per day, then orders each day's stops to minimize backtracking, using the Maps API for real travel times rather than straight-line distance. The interface stays intentionally plain — a day-by-day list, drag to reorder, a map alongside for a sanity check.

The result

I've used it to plan four trips of my own so far, and it's cut trip-planning time from a couple of evenings down to about twenty minutes of pasting in place names and nudging the order. The next thing on the list is handling multi-city trips, where the day-clustering logic needs to account for a change of base entirely.
