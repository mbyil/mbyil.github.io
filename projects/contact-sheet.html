Contact Sheet

An open-source gallery generator that turns a folder of RAW exports into a static, fast-loading photo site like the one this page lives on.

RoleDeveloper

LinksSource ↗

Overview

Contact Sheet is a small command-line tool: point it at a folder of exported photos, and it generates a static gallery site — resized images, a lightbox, captions pulled from a simple text file — with no server and no database to maintain.

The problem

I wanted somewhere to put photos that wasn't a social platform's algorithm deciding who saw them, but every existing gallery tool either needed a CMS and hosting bill, or produced pages that loaded slowly because nothing was resized or compressed properly. I wanted the simplicity of a folder of files with the polish of a proper gallery.

The approach

The pipeline is intentionally boring: read a folder, generate two or three sizes of each image, write out plain HTML and CSS, done. Captions and ordering come from a small YAML file next to the photos so there's no separate admin interface to maintain — the file structure is the source of truth.

photos/
  001-dolomites.jpg
  002-lisbon.jpg
  gallery.yaml

The result

The photography section of this site is generated with an early version of this tool. It's fast, it costs nothing to host, and updating it is just adding a file to a folder and re-running one command. Next up is support for basic EXIF display, so lens and settings can show up automatically instead of being typed in by hand.
